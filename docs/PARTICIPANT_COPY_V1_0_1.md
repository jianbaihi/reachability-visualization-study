## Reproduce Chrome checks

Serve the repository on localhost:8021, then:

```sh
PLAYWRIGHT_MODULE=/path/to/playwright node research-tools/test-participant-copy-compatibility.cjs
node research-tools/audit-participant-copy.mjs output/playwright/audit-results.json
python3 research-tools/merge_survey_results.py output/playwright/merge
```

Set CANDIDATE_URL and CHROME_EXECUTABLE when needed. Browser results and disposable test sessions are under output/playwright. Only the isolated test browser clears its own project storage; production runtime never clears storage or migrates legacy keys.

Safari reproduction: start `/usr/bin/safaridriver -p 4445`, create a Safari WebDriver session, then set SAFARI_SESSION to its session ID and run `node research-tools/test-participant-copy-safari.cjs`. Legacy fixtures are generated by the Chrome compatibility check above.
