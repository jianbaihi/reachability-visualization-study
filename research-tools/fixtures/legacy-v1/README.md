# Legacy session regression fixtures

These are disposable automated-test sessions generated by the original questionnaire-v1.0.0 runtime, never participant research data. They capture T3 ACTIVE, T5 ACTIVE, PREVis group 2 and completion. Formal instances, answers and stable IDs come from the original V4 generator.

The V2 browser tests replay each fixture under both v1.0.0 and v1.0.1 storage keys. The v1.0.1 replay uses the same session schema and V4 task instances with questionnaireVersion set to v1.0.1. Assertions compare identity, seed, instances, selection, answers, version and old asset use before/after loading V2 code. These fixtures must not be merged into real study data.
